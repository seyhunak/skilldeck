# Claim rating scale

Use one rating per claim. Ratings describe the claim as written in the checked text, judged against the best available evidence at the time of checking.

| Rating | Use when | Typical correction |
|---|---|---|
| Accurate | The claim matches the original source in substance, numbers, scope, and context. | None |
| Accurate with caveat | Substantially right but missing a qualifier that a reader needs (date, scope, estimate status, denominator). | Add the qualifier |
| Misleading | Literally defensible but framed so readers would draw a wrong conclusion (cherry-picked period, relative risk without baseline, correlation as causation). | Reframe or add context |
| Inaccurate | Contradicted by the original or best available source (wrong number, wrong date, misquote, misattribution). | Replace with the correct fact or remove |
| Outdated | Was accurate but has been superseded by newer data. | Update with the latest figure and date |
| Disputed | Credible experts or sources disagree and evidence does not settle it. | Present as contested, attribute positions |
| Unverifiable | No locatable source supports or refutes it after a reasonable search. | Remove or attribute clearly as unverified |
| Needs clarification | Too vague to check without knowing what was meant. | Make the claim specific |

## Common distortion checklist

- Percentage versus percentage points.
- Relative versus absolute change; small baselines.
- Mismatched denominators (per capita, per user, per year).
- Nominal versus inflation-adjusted money; currency conversions.
- Survey results generalised beyond the surveyed population.
- Preprint or press release presented as peer-reviewed finding.
- Quote accurate but context changes its meaning.
- Image or video real but from a different time or place.
- Rounding that crosses a meaningful threshold.
